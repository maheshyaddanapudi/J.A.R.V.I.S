## 4. Real bug found by the live run (fixed)

`Announcer.inQuietHours()` consulted only the window (`proactive.quietHours.start`/`.end`), never `proactive.quietHours.enabled` — so switching quiet hours OFF did not release deferred announcements. Fixed (announce.ts checks the enabled flag first) + regression test ("quiet hours switched OFF hold nothing back"). Suite after fix: **432/432 pass**.

## 9. A real fix first: the night's null hypothesis is the LIVE surface

Preparing the scenario surfaced a genuine design flaw: the baseline ran the lab
kernel's factory-seeded state while the researcher proposed changes relative to the
LIVE surface — so a user-edited persona would never actually be what candidates were
measured against. Fixed (`night.ts`): `runNight()` snapshots the live on-surface
state once (active persona, judge templates, overridden `LAB_SETTINGS_SURFACE`
values) and rides it under the baseline AND under every trial, with the candidate's
one change overlaid (collision → candidate wins; its persona activates last). New
test proves baseline + all 3 trials carry the live persona/knob. Suite **433/433**.
