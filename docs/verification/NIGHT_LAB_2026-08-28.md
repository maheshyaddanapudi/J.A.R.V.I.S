## 4. Real bug found by the live run (fixed)

`Announcer.inQuietHours()` consulted only the window (`proactive.quietHours.start`/`.end`), never `proactive.quietHours.enabled` — so switching quiet hours OFF did not release deferred announcements. Fixed (announce.ts checks the enabled flag first) + regression test ("quiet hours switched OFF hold nothing back"). Suite after fix: **432/432 pass**.
